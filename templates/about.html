About Vakya Vani

Vakya Vani is an intelligent Sanskrit verse recitation and analysis platform that integrates poetic meter detection, translation, and rhythmic chanting into a single interactive system.

📜 What the System Does

  • Detects Sanskrit poetic meter automatically
  • Identifies Guru–Laghu syllable structure
  • Generates rhythmic chanting audio
  • Provides English translation instantly
  • Highlights words during pronunciation

🎯 Project Objective

Vakya Vani preserves traditional Sanskrit chanting methods using computational linguistics, making structured verse learning accessible to students and researchers.

⚙️ Technologies Used

  • Python
  • Flask Framework
  • HTML & CSS
  • JavaScript Animation
  • Text-to-Speech Engine

🌍 Educational Impact

The platform helps learners visualize pronunciation, understand verse structure, and experience authentic rhythmic chanting digitally.
