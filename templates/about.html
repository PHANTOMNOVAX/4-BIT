About This Project

This system demonstrates automatic Sanskrit verse recitation using computational Chandas detection and melodic chanting simulation. Features include:

  • Meter detection (Anushtubh, Trishtubh, Jagati)
  • Automatic translation
  • Syllable-aware chanting
  • Interactive visualization
