About This Project

This system demonstrates a computational approach to Sanskrit poetic recitation using classical Chandas (metrical structure) combined with melodic rhythm simulation. The engine performs:

  • Automatic Sanskrit verse input processing
  • Meter detection (Anushtubh, Trishtubh, Jagati)
  • Semantic translation to English
  • Syllable-aware chanting generation
  • Interactive chant visualization

Designed as a Proof-of-Concept for Chanda-Melodic constrained Sanskrit recitation.
